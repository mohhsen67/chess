# شطرنج

ابزاری برای پیدا کردن ضعف‌های تکراری در بازی‌های شطرنج، از روی بازی‌های خودت در Chess.com یا Lichess.

- **گزارش:** ضعف اصلی، الگوهای تکراری، امتیاز در هر گشایش، مدیریت زمان
- **بازی‌ها:** مرور حرکت به حرکت، با اشتباه‌های مشخص‌شده
- **تمرین:** موقعیت‌هایی از بازی‌های خودت که در آن مهره از دست رفت

سایت: https://mohhsen67.github.io/chess

## ساختار

- `index.html` — کل سایت در یک فایل (خروجی ساخت)
- `src/engine.js` — قوانین شطرنج، خواندن PGN، جست‌وجوی مهره‌ای
- `src/analyze.js` — ساختن گزارش از بازی‌ها
- `src/ui.js` و `src/template.html` — رابط کاربری

## داده‌ها

بازی‌ها داخل خود مخزن، در پوشه‌ی `data/`، نگه داشته می‌شوند:

- `data/players.txt` — فهرست نام‌های کاربری Chess.com که باید به‌روز بمانند
- `data/<username>.pgn` — همه‌ی بازی‌های هر بازیکن

کار خودکار `.github/workflows/sync.yml` هر ۶ ساعت بازی‌های تازه را از Chess.com می‌گیرد و به این فایل‌ها اضافه می‌کند. بار اول کل تاریخچه‌ی بازیکن گرفته می‌شود. سایت اول بازی‌های همین پوشه را می‌خواند و بازی‌های چند ساعت اخیر را هم مستقیم از Chess.com اضافه می‌کند.

ساخت دوباره‌ی `index.html`:

```
node src/build.js
```
