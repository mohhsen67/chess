# شطرنج

ابزاری برای پیدا کردن ضعف‌های تکراری در بازی‌های شطرنج، از روی بازی‌های خودت در Chess.com یا Lichess.

- **گزارش:** ضعف اصلی، الگوهای تکراری، امتیاز در هر گشایش، مدیریت زمان
- **بازی‌ها:** مرور حرکت به حرکت، با اشتباه‌های مشخص‌شده
- **تمرین:** موقعیت‌هایی از بازی‌های خودت که در آن مهره از دست رفت

سایت: https://mohhsen67.github.io/chess

## ساختار

- `index.html` — کل سایت در یک فایل (خروجی ساخت)
- `src/engine.js` — قوانین شطرنج، خواندن PGN، جست‌وجوی مهره‌ای
- `src/analyze.js` — ساختن گزارش از بازی‌ها
- `src/ui.js` و `src/template.html` — رابط کاربری و اتصال به Supabase
- `supabase/schema.sql` — جدول‌ها، دسترسی‌ها و توابع پایگاه داده

## حساب‌ها و داده‌ها

سایت به یک پروژه‌ی Supabase وصل است (ورود کاربران + پایگاه داده‌ی Postgres). کل ساختار پایگاه داده در `supabase/schema.sql` است و یک بار در SQL Editor پروژه اجرا می‌شود.

- هر کاربر با ایمیل ثبت‌نام می‌کند و حساب Chess.com خودش را با گذاشتن یک کد در پروفایل Chess.com تأیید می‌کند.
- خود پایگاه داده بازی‌ها را از Chess.com می‌گیرد (بار اول کل تاریخچه، بعد هر ۶ ساعت بازی‌های تازه).
- هر کس فقط بازی‌ها و پیشرفت تمرین خودش را می‌بیند (Row Level Security).
- باشگاه‌ها با یک کد ۶ حرفی عضو می‌گیرند و رده‌بندی داخلی دارند.

ساخت دوباره‌ی `index.html`:

```
node src/build.js
```
